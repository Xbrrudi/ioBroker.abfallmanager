# Release procedure for ioBroker.wastemanager

The package is available on npm. See [MIGRATION.md](MIGRATION.md) for the migration from `abfallmanager` and rollback instructions.

1. Review and merge the release PR after the checks pass. Wait for **Test and Release** on the resulting `main` commit.
2. Keep `release.yml` in state `disabled_manually`. In the npm package settings, verify the GitHub Actions trusted publisher for `Xbrrudi/ioBroker.wastemanager`, workflow `test-and-release.yml`, with no environment. Enable npm publish and leave dist-tag permission disabled. If the pending connection expired, re-establish it in npm settings before tagging. Confirm that bluefox has accepted package ownership with `npm owner ls iobroker.wastemanager`.
3. Tag the approved `main` commit with `git tag v0.21.9 <approved-main-commit>` and send it with `git push origin refs/tags/v0.21.9`. The tagged workflow tests, builds and verifies the TGZ, publishes via OIDC with provenance and attaches the verified TGZ to the GitHub release. Use **Re-run failed jobs** after a recoverable failure to reuse the verified artifact. If npm already has the version, the workflow compares SHA-512 before continuing.
4. Check that `npm view iobroker.wastemanager@latest version dist.integrity dist.attestations --json` reports version `0.21.9` and a provenance attestation. Compare `dist.integrity` to `sha512-` followed by the base64 SHA-512 of the attached TGZ. Use `openssl dgst -sha512 -binary iobroker.wastemanager-0.21.9.tgz | openssl base64 -A` to calculate the digest.
5. Rerun the official Repochecker as a new adapter. After the GitHub release and npm checks pass, sign in to [iobroker.dev](https://www.iobroker.dev/) with GitHub, open Waste Manager, choose **Manage**, then **ADD TO LATEST**. The [ioBroker repository instructions](https://github.com/ioBroker/ioBroker.repositories) also document the GitHub pull request route.
