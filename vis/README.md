# VIS-2 Integration – Stand v0.8.0

Enthalten sind vier freigestellte, fotorealistische PNG-Bilder unter `assets/`.

**Sofortiger manueller VIS-2-Test:** Ein Standard-HTML-Widget auf die Seite ziehen,
`widget-html-template.html` in das HTML-Feld übernehmen, Bildpfad bei Bedarf
auf `rest.png`, `bio.png` oder `papier.png` ändern. Widget-Hintergrund transparent,
Breite/Höhe und Position im VIS-2-Editor einstellen. Die VIS-2-eigene
Sichtbarkeitsbedingung auf `wastemanager.0.bins.gelb.visible == true` setzen.
Die Tonne verschwindet dann ohne sichtbaren Hintergrund.

**Noch nicht vorhanden:** Automatische Registrierung einer nativen VIS-2-Widgetgruppe.
Diese erfordert ein separates, nach VIS-2-Spezifikation gebautes Widgetset.
Eine automatische Registrierung wird mit diesem Paket nicht behauptet.
